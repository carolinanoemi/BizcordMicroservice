\# Messaging Service



Microservice for the Bizcord platform.



Manages sending, storing, editing, and deleting messages in real time. Handles the chat payload and integrates WebSocket connections for live delivery.



\## Project Structure



\- `src/MessagingService` - The API project

\- `tests/MessagingService.Tests` - Unit tests



\## How to run



```bash

dotnet run --project src/MessagingService

```
